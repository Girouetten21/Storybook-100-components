# 🧩 Kinetic Pixel Menu

**Component #53 - Assembly Volumetric Fullscreen Navigation**

If Component #52 destroyed the world, this reconstructs it. A full screen immersive overlay navigation unit that builds its solid background structurally by gathering hundreds of independent floating DOM elements from across Z-space mathematical randomized coordinates (`from: "random"`), actively converging them into an exact perfectly calculated CSS Grid to render a monolithic structural door.

### 📐 Mechanical Construction
Instead of scattering outward via `.to` animations, the internal timeline forces a synchronized inversion via `tl.fromTo`. A central interaction `useEffect` controller simply parses the timeline in `.play()` on un-click or `.reverse()` respectively returning the environment safely to normal.

### Use case 
Ideal for portfolios or high immersion corporate entities needing absolute, un-ignorable attention shifted upon toggle. Drop `<KineticPixelMenu />` anywhere in the primary `<App />` shell.
