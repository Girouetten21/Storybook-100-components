# 💎 Gemstone Refraction Section

**Component #58 - Elite Luxury Boutique Explorer**

The **Gemstone Refraction Section** is a prestigious, cinematic informational module designed for high-end jewelry and mineralogy brands. It blends technical precision with artistic editorial layout, focusing on the clarity, refractive index, and heritage of world-class gemstones.

### ⚜️ Key Features:
*   **Interactive Refraction Viewer**: Users can explore different gemstones (Emerald, Sapphire, Diamond) through an interactive HUD that seamlessly cross-fades assets using GSAP.
*   **Crystalline Typography**: Features a pairing of the elegant `Fraunces` (Serif) with the technical precision of `JetBrains Mono`, creating a high-end data-driven editorial look.
*   **Infinite Geometric Rotation**: The featured gemstone uses a continuous GSAP rotation and "hover-react" scaling, mimicking the inspection of a real physical stone under jeweler's loupe.
*   **Atmospheric Obsidian Palette**: Dressed in a deep dark theme (`#050505`) with a subtle `radial-gradient` flare and background-to-foreground z-index depth.
*   **Technical Metadata HUD**: Displays crucial mineralogical data (Hardness, Gravity, Refractive Index) with a staggered reveal on entry.

### 🚀 Performance & Design:
*   **Asset-Swapping Navigation**: Implemented with pre-loaded imagery and GSAP timelines to ensure zero-latency when interacting with different gemstone categories.
*   **Cinematic Glare Layer**: A dedicated SVG-like glow follows the active gemstone, adding a layer of lighting depth that enhances the "3D" feel of the 2D assets.
*   **Responsive Editorial Stack**: Transitions from a wide desktop split-screen to a vertically centered, high-impact mobile presentation with adjusted typographic weights.
