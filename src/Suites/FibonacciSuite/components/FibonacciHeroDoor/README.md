# 🚪 Fibonacci Hero Door

**Component #51 - The Interactive Sequence Seal**

A highly interactive block-gate or "Hero Door" component mapping identical strict Golden Ratio fractional mathematics from Component 50. Instead of behaving as a menu floating outwards, this completely seals the user out of the application until they click the glowing golden eye nested in the `{1, 1b}` interior structural block.

### 📐 Animation Logic
- **The Eye**: A circular 'UNLOCK' button resides in `panel-1b`. It pulses autonomously with an infinite sine yoyo loop simulating a "breathing" state.
- **The Seal**: The Golden Spiral SVG initializes at `stroke-dashoffset: 0`, completely binding all fractions together.
- **The Scatter / Unlocking**: When triggered, GSAP forcefully breaks apart the CSS layout by tracking the fractional grids and physically rotating/transforming them outwardly (-100vw, +100vh scaling) simulating shards flying away to reveal the under layer.

To implement, simply inject `<FibonacciHeroDoor />` anywhere into your Main Layout before traditional scroll flow content begins. It natively intercepts `wheel/touchmove` preventing the user from scrolling down around it.
